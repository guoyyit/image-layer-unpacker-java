# Image Layer Unpacker

容器镜像分层解包与合并视图文件系统服务。镜像由多个只读 tar 层组成，服务按提交顺序将它们叠加为一个逻辑合并视图，通过 HTTP 对外提供层解包、视图读取与层管理能力。所有数据仅落本地磁盘（默认为临时目录），不依赖任何外部服务。

## 构建与运行

```bash
mvn spring-boot:run
mvn test
```

可选配置（`application.properties` 或环境变量）：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `imagelayer.storage-dir` | 系统临时目录 | 层数据与注册表的本地根目录；不设置时每次启动新建临时目录 |
| `imagelayer.max-layer-bytes` | 10485760 | 单层解包后总字节上限 |
| `imagelayer.max-total-bytes` | 104857600 | 全部已提交层解包字节总和上限 |

## HTTP 接口

所有层归档以 `application/octet-stream` 原始 tar 字节上传。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/layers/{id}` | 上传并原子解包提交一层；同 id 重复提交为幂等返回 |
| `GET` | `/api/layers` | 按提交顺序列出层元数据（白名单、opaque 目录、大小、sha256） |
| `GET` | `/api/layers/{id}` | 查询单层元数据 |
| `DELETE` | `/api/layers/{id}` | 删除层并回收空间 |
| `GET` | `/api/view/list?path=/dir` | 列出合并视图目录，返回 `path/type/size` |
| `GET` | `/api/view/read?path=/dir/file` | 读取合并视图中的常规文件内容 |
| `GET` | `/api/view/stat?path=/dir` | 查询合并视图节点类型（`file`/`directory`/`symlink`） |

错误响应统一为 `{ "error": "...", "message": "..." }`，状态码包括 `400`（非法请求/不安全归档）、`404`（不存在）、`409`（冲突）、`413`（超配额）、`422`（损坏或截断归档）。

## 合并语义

层按提交序号自下而上叠加（先提交的是下层）。合并视图对每个路径从最高层向下查找第一个“决定性”层：

- **文件覆盖**：上层同名文件、符号链接覆盖下层同名条目。
- **目录合并**：同名目录逐层合并；即使归档未显式包含目录条目，只要层内存在 `a/b.txt` 这样的路径，`a` 也作为虚拟目录参与合并。
- **删除标记（whiteout）**：上层目录中名为 `.wh.<name>` 的空文件表示删除下层同目录下的 `<name>`（文件或目录）。例如 `etc/.wh.hosts` 会隐藏所有下层的 `etc/hosts`。
- **opaque 目录**：目录中名为 `.wh..wh..opq` 的空文件表示该目录在本层“不透明”，只隐藏该目录在更低层中的内容，不影响本层自身新增条目，也不隐藏目录本身。
- 白名单标记本身不会出现在合并视图中。

## 安全边界与归档校验

仅接受经典 **ustar** 归档（兼容 POSIX `ustar\0` 与 GNU `ustar ` magic），且每条目经过严格校验：

- 拒绝绝对路径、`..` 路径穿越、反斜杠路径与 NUL 字节；解包落盘使用规范化后的路径再次确认仍位于层根之内。
- 拒绝绝对符号链接与解析后逃逸层根的相对符号链接；符号链接以 `NOFOLLOW` 方式创建，读取视图不跟随链接越界。
- 硬链接目标必须是同一层内已存在的常规文件。
- 拒绝设备节点、FIFO、套接字等非文件/目录/链接类型，拒绝 PAX/GNU 扩展头等非 ustar 特性。
- 校验 tar 头校验和，截断、短读、大小不符、缺少结束零块等均判定为损坏归档。
- 每条目大小与单层累计大小实时受配额约束。

## 原子性、并发与回滚

- 每层先写入独立 `staging` 目录，完整通过两遍处理（先在内存中校验全部条目，再落盘）后经目录原子重命名提交；任一步失败都会清理 staging 与半写根目录，已提交层不受影响，同 id 重试结果确定。
- 注册表 `registry.json` 通过临时文件 + 原子移动更新；提交与删除在同一把读写锁的写锁下串行化，视图读取在快照（提交层列表副本）下进行，因此读取要么看到整层生效前、要么生效后的自洽状态，不会观察到层内半写数据或跨层混合视图。
- 删除与解包互斥：进行中的读取持有读锁期间，层目录不会被删除回收。

## 重启恢复

启动时执行恢复扫描：

- 已在注册表且 `root/` 完整的层直接可用，不会重复解包。
- 残留的 `*.staging-*` 目录一律清理。
- 存在 `blob.tar` 但未完成提交（无注册表记录或缺少 `root/`）的层被识别为“未完成层”，使用其原始归档自动重新解包提交；若归档已损坏无法恢复，则清理该层目录并记录告警，不影响其它层。
- 已提交层在注册表与每层 `meta.json` 中持久化，崩溃后不丢失。

## 存储布局

```
<storage-dir>/
  registry.json                 # 已提交层有序注册表（原子写入）
  layers/
    <layer-id>/
      blob.tar                  # 原始归档（保留用于崩溃后重新解包）
      root/                     # 解包后的只读层内容
      meta.json                 # 层元数据
    <layer-id>.staging-<token>/ # 解包中的临时目录
```
